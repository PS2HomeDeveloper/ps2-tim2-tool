# ps2-tim2-tool
A complete TIM2 (.tm2) texture toolkit for PlayStation 2: convert images to TIM2 and extract TIM2 back to images, with full swizzle, CLUT, and mipmap support across 4-bit, 8-bit, 16-bit, and 32-bit formats. Includes verification, metadata inspection, batch conversion, and dimension validation. Built for PS2 homebrew development and modding.
